# HEARTBEAT.md - CEO 任务汇报配置

## 模式

**人工分派 + 主动汇报**：Agent 完成后 @CEO 汇报 → CEO 验收 → CEO 分派下一步。

## 汇报模板

### 任务完成

```
@CEO
任务：[名称]
状态：✅ 已完成
交付物：[文件/链接]
建议下一步：@[next-agent] [任务]
```

### 任务阻塞

```
@CEO
任务：[名称]
状态：⏸️ 已阻塞
原因：[说明]
需要：[帮助]
```

## 流转规则

1. Agent 完成任务 → @CEO 汇报交付物
2. **CEO 确认后才能分派下一步**（不能自动流转）
3. 定时汇报：每 2 小时汇总任务状态
