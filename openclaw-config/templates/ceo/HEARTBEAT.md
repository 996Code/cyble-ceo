# HEARTBEAT.md - CEO 任务汇报配置

## 📋 配置说明

**模式**：方案 A - 人工分派 + 主动汇报

**原则**：
- ✅ agent 完成任务后主动@CEO 汇报
- ✅ CEO 验收后手动分派下一步
- ✅ 保持 CEO 决策权
- ✅ 不过度自动化

---

## 📢 汇报模板

### 任务完成汇报

```markdown
@CEO
**任务**：[任务名称]
**状态**：✅ 已完成

**交付物**：
- [文件 1 路径/链接]
- [文件 2 路径/链接]

**验收标准**：
- [x] 标准 1
- [x] 标准 2

**建议下一步**：@next-agent [下一步任务]
```

**CEO 确认后**：
- ✅ 自动打开交付物给 CEO 查看
- ⏸️ 等待 CEO 确认后才能分派下一步

### 任务阻塞汇报

```markdown
@CEO
**任务**：[任务名称]
**状态**：⏸️ 已阻塞

**阻塞原因**：
[详细说明]

**需要帮助**：
[具体需要什么]

**预计影响**：
[延期时间/其他影响]
```

### 任务超时汇报

```markdown
@CEO
**任务**：[任务名称]
**状态**：⚠️ 可能超时

**原计划**：[完成时间]
**现预计**：[新完成时间]
**超时原因**：[说明]

**补救措施**：
[计划]
```

---

## 🔄 任务流转流程

```
CEO 分派 → agent 执行 → 完成汇报 → CEO 确认 → CEO 分派下一步
   │          │          │          │            │
   │          │          │          │            └→ 继续流转
   │          │          │          └→ ✅ 确认后
   │          │          └→ @CEO + 交付物
   │          └→ 定期进度（每 2 小时）
   └→ @agent-id

⏰ 定时汇报：每 2 小时汇总所有任务状态
```

**关键点**：
- ⚠️ **产品设计完毕后必须找 CEO 确认**
- ⚠️ **CEO 确认后才能分派下一步**
- ⚠️ **不能自动流转到架构师**
