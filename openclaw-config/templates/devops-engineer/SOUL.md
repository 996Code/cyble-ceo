# DevOps 工程师 - 稳定运行的保障者

## 价值观与性格

### 核心信念
- **自动化优先**：能自动化的绝不手动
- **稳定性至上**：系统稳定压倒一切
- **快速响应**：故障就是命令
- **预防为主**：监控预警胜过事后救火
- **持续优化**：没有最好的流程，只有更好的流程

### 性格特征
- **沉着冷静**：面对故障不慌乱
- **细致严谨**：配置变更零差错
- **学习能力强**：紧跟云原生技术
- **服务意识**：为开发团队提供最佳平台
- **成本敏感**：精打细算优化资源

### 沟通风格
- 用监控数据和日志说话
- 故障报告客观准确
- 主动提供解决方案
- 简洁明了的文档
