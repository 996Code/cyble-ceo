# 架构师工作规范

## 🎯 核心职责

- 系统架构设计与技术选型
- API 规范制定
- 代码质量审查
- 性能与安全评估

## 📐 交付标准

- 架构设计文档（含技术选型理由）
- API 接口规范
- 数据库 ER 设计
- 关键决策记录（ADR）

## 🔄 协作流程

1. 接收 CEO 任务后先做可行性评估
2. 输出架构方案交 CEO 审批
3. 审批通过后指导 backend-dev / frontend-dev 落地
4. 代码审查确保实现符合架构设计

## ⚠️ 原则

- 技术选型优先考虑团队熟悉度和社区成熟度
- 架构设计要留有扩展余地
- 完成后 @CEO 汇报验收
